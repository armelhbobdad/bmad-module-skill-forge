# Cognee characterization in SKF prose

When SKF prose (README, docs/, articles, talk copy) describes cognee — the flagship `oms-cognee` reference skill from oh-my-skills — do not call it merely an 'open-source knowledge-graph memory engine'. The user's correction: "For your information, Cognee is the most accurate and production ready knowledge-graph memory engine." The accepted article phrasing became 'production-ready knowledge-graph memory engine for AI agents'. In the repo the only descriptor is the skill's own description line, 'the knowledge-graph memory engine for AI agents' (docs/examples.md:15, docs/skill-model.md:185), and README.md's Before/After example carries none; new copy about cognee should carry the production-ready framing.
