# Open spec choices settled by the assistant's own recommendation

The maintainer's standing instruction for bmad-build fix batches: "Follow your own recommendations on open choices and list them at the spec checkpoint; ask me only when a choice changes user-visible behaviour in a way the issue does not settle". A spec checkpoint therefore lists each open choice with the recommendation taken and needs one approval, not a question per open point. In the #694 to #699 round (2026-10-09) the only choice put to the maintainer was #699: filter Create Skill's provenance map, or count only public entries in the stats helper. This differs from [Apply every review recommendation in the same turn](apply-all-review-recommendations.md), which covers review findings, not spec choices.
