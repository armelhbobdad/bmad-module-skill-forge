# ProbeOrder frontmatter for every shared helper script invocation

Every `uv run` of a `src/shared/scripts/*.py` helper (and the loads of the shared references `description-guard-protocol.md`, `feasibility-report-schema.md` and `tessl-review.md`; other shared references are loaded by module-root-relative paths such as `shared/references/pipeline-contracts.md` or an `outputContractSchema` value) from a `src/skf-*/references/*.md` step is wired through a frontmatter `<name>ProbeOrder` array that lists `{project-root}/_bmad/skf/shared/scripts/<script>.py` (installed module) first and `{project-root}/src/shared/scripts/<script>.py` (dev checkout) second, resolved in prose as "Resolve `{<name>Helper}` from `{<name>ProbeOrder}`; first existing path wins. HALT if no candidate exists", and then invoked only as `uv run {<name>Helper}` (see `src/skf-setup/references/write-config.md` frontmatter for the canonical shape; 73 step files carry a ProbeOrder). The rule exists because an installed module lives under `_bmad/skf/` with no `src/` tree; the defect recurred in June 2026 (commit 2ebc7a45) in skf-create-skill, skf-brief-skill and skf-analyze-source, and again as #512, where create-skill `validate.md` and update-skill `write.md` loaded `{project-root}/src/shared/references/description-guard-protocol.md` directly (now `descriptionGuardProtocolProbeOrder`, an advisory load because each step restates the guard rules it acts on). Since commit 61d91c38 (#510, #512) three gates catch part of this class: `validate:refs` (`tools/validate-file-refs.js` `findSrcPathRefs`) fails any `{project-root}/src/<path>` in src/, fenced code and `.py`/`.toml`/`.json` files included, that its `{project-root}/_bmad/skf/<path>` twin does not precede on the same line or the line before; `test/test-skf-helper-call-contract.py` (`test_every_helper_placeholder_is_bound`) fails a `{...Helper}` call that no frontmatter binds; and Test Suite 7 of `test/test-installation-components.js` resolves every ProbeOrder in a temporary install. Still uncaught: a bare `src/shared/scripts/...` path written without `{project-root}` (the validator header lists it as deferred), a placeholder no file binds whose name does not end in `Helper` (the contract test skips it), and a placeholder a file never binds itself while another file binds it, since frontmatter variables are file-scoped but the contract test falls back to that agreed binding. The frontmatter is the single source of truth: prose references the variable and never re-enumerates paths, and the HALT is deliberate — do not fall back to prose-driven LLM computation for what the helper does (content hashes, symlink flips, drift guards, manifest counts, scope classification), because two runs would then disagree. The one remaining in-prompt fallback is the Quick-tier metadata renderer in `src/skf-quick-skill/references/compile.md`; do not copy it into forge-tier steps.
